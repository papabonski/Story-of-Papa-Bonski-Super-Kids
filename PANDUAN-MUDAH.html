1. Gambaran Singkat Aplikasi

Mykarakids membuat buku cerita anak personal. Orang tua memilih profil anak, tema, masalah anak hari ini, level bahasa, dan gaya ilustrasi. Aplikasi membuat teks terlebih dulu, lalu orang tua bisa meninjau dan mengedit sebelum gambar serta audio dibuat.

Fitur untuk orang tua

  • Profil anak reusable: nama, usia, gender, foto, deskripsi karakter.
  • Template masalah anak: susah tidur, tidak mau sayur, marah, takut sekolah, gadget.
  • Preview dan edit cerita sebelum biaya gambar/audio dipakai.
  • Flipbook dengan gambar, audio, moral, doa, dan parent guide.
  • Progress baca, favorit, share link privat, export PDF, download ZIP.

Fitur untuk reseller

  • Dashboard admin white-label di /admin.
  • Ubah brand, warna, logo, provider AI, suara TTS, limit, dan harga paket.
  • PWA: aplikasi bisa di-install di HP dan tablet.
  • Cerita Anak Digital English: video, PDF, ringkasan, vocabulary IPA+TTS, kuis.
  • Job queue server-side agar proses tetap jalan walau browser ditutup.
Prinsip mudahnya: Supabase menyimpan data, Gemini membuat cerita/gambar/audio, Vercel membuat aplikasi online, dan admin dashboard mengatur tampilan bisnis tanpa edit code.

3. Setup Supabase dengan Satu SQL

Semua schema database sudah digabung ke satu file: supabase/migrations/0001_init.sql. File ini aman dijalankan ulang.

1
Buat project Supabase
Buka supabase.com, buat project baru, lalu tunggu sampai database siap.
2
Aktifkan Anonymous Auth
Masuk ke Authentication, buka Providers, aktifkan Anonymous. Ini membuat tiap perangkat punya identitas pemilik cerita tanpa halaman login.
3
Jalankan SQL gabungan
Buka SQL Editor, salin seluruh isi supabase/migrations/0001_init.sql, lalu klik Run.
4
Ambil API keys
Dari Project Settings - API, salin Project URL, anon key, dan service role key.

Yang dibuat oleh SQL ini

  • Tabel children, stories, scenes, story_jobs, white_label_settings.
  • Kolom review teks, share token, progress baca, favorit, language level, illustration style.
  • Row Level Security agar user hanya melihat data miliknya.
  • Bucket child-photos privat dan story-assets publik.
Jangan jalankan migrasi lama terpisah. Versi terbaru hanya memakai 0001_init.sql. Jika sebelumnya ada error "kolom tidak ditemukan", jalankan ulang file ini.

4. Isi Environment Variables

Buat file .env.local untuk lokal, lalu isi variabel yang sama di Vercel saat deploy. 

NEXT_PUBLIC_SUPABASE_URL="https://project.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="anon-key"
SUPABASE_SERVICE_ROLE_KEY="service-role-key"

STORY_WORKER_SECRET="rahasia-worker-panjang"
STORY_WORKER_AUTOKICK="true"
STORY_WORKER_AUTOKICK_LIMIT="5"
CRON_SECRET="rahasia-cron-panjang-opsional"
ADMIN_DASHBOARD_SECRET="rahasia-admin-opsional"

GEMINI_API_KEY="kunci-google-ai-studio"

IMAGE_RESOLUTION="1K"
KIE_API_KEY=""
IMAGE_PROVIDER="gemini"

NEXT_PUBLIC_STORY_QUEUE_POLL_MS="2500"
NEXT_PUBLIC_STORY_QUEUE_MAX_POLLS="240"
NEXT_PUBLIC_STORY_QUEUE_NUDGE_EVERY_POLLS="4"
Env Status Fungsi
NEXT_PUBLIC_SUPABASE_URL Wajib Alamat project Supabase.
NEXT_PUBLIC_SUPABASE_ANON_KEY Wajib Dipakai browser untuk akses data user dengan RLS.
SUPABASE_SERVICE_ROLE_KEY Wajib Dipakai server untuk worker, admin, export, dan asset generation.
STORY_WORKER_SECRET Wajib Melindungi endpoint worker /api/jobs/process.
STORY_WORKER_AUTOKICK Disarankan Isi true agar worker langsung dipicu saat user membuat cerita.
CRON_SECRET Opsional Secret untuk cron aman ke /api/jobs/cron.
STORY_WORKER_AUTOKICK_LIMIT Opsional Jumlah job yang diambil sekali autokick. Default 5.
ADMIN_DASHBOARD_SECRET Opsional Password khusus dashboard admin. Jika kosong, memakai worker secret.
GEMINI_API_KEY Wajib Kunci AI untuk cerita, gambar, audio, quality check, vocabulary TTS.
Apa isi tiga env worker?
  • STORY_WORKER_SECRET: isi teks acak panjang buatan sendiri, bukan API key Supabase/Gemini. Dipakai server untuk memproses antrean cerita.
  • STORY_WORKER_AUTOKICK: isi true. Jika false dan tidak ada cron/worker eksternal, cerita bisa stuck di "Antrean teks".
  • STORY_WORKER_AUTOKICK_LIMIT: boleh dibiarkan 5 untuk awal. Naikkan perlahan jika trafik cerita mulai ramai.
  • CRON_SECRET: isi teks acak panjang lain jika memakai cron. Kirim sebagai header Authorization: Bearer <CRON_SECRET>.

Buat secret acak dari terminal:

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

Gunakan nilai hasil generate sendiri. Jangan memakai contoh rahasia dari panduan.

Setelah env diubah di Vercel, wajib Redeploy. Env baru tidak aktif pada deployment lama.

5. Jalankan di Lokal

Gunakan lokal untuk memastikan semua env benar sebelum deploy.

1
Install package
npm install
2
Jalankan dev server
npm run dev
Buka http://localhost:3000.
3
Tes AI key
npm run test:live
Jika semua OK, Gemini text, image, dan TTS siap dipakai.
4
Cek compile
npm run build

6. Deploy ke Vercel

  1. Push kode ke GitHub.
  2. Buka Vercel, pilih New Project, import repository.
  3. Masukkan semua env dari .env.local ke Environment Variables, terutama Supabase, Gemini, STORY_WORKER_SECRET, dan STORY_WORKER_AUTOKICK=true.
  4. Pastikan env diterapkan ke environment Production.
  5. Klik Deploy.
  6. Setelah deploy, buka domain Vercel dan tes aplikasi.
Catatan komersial: Untuk aplikasi white-label yang dijual ulang, gunakan Vercel Pro agar sesuai kebutuhan bisnis.
Setelah ubah env: buka Deployments di Vercel, pilih deployment terbaru, lalu klik Redeploy. Tanpa redeploy, worker masih memakai env lama.

7. Cara Pakai Aplikasi

Alur terbaru sengaja dibuat hemat biaya: teks dibuat dan disetujui dulu, baru gambar/audio.

1
Buat atau pilih profil anak
Isi nama, usia, gender, foto, dan character description. Profil ini bisa dipakai ulang.
2
Pilih kebutuhan cerita
Pilih template masalah anak hari ini atau pilih tema/subtema manual. Tentukan level bahasa: Balita, TK, SD awal, atau SD besar.
3
Pilih gaya ilustrasi
Contoh: watercolor, 3D cartoon, pastel storybook, anime soft, paper cutout.
4
Generate teks dan review
Baca judul, opener, setiap scene, moral, doa, dan parent guide. Gunakan regenerate scene, buat lebih lucu, lebih Islami, atau edit manual.
5
Setujui teks
Setelah teks disetujui, job queue mulai membuat gambar dan audio di server. Jika muncul pesan antrean belum diambil, klik Cek worker sekarang untuk melihat diagnostik autokick.
6
Baca dan bagikan
Buka flipbook, tandai favorit, lanjutkan progress baca, buat share link privat, export PDF, atau download ZIP lengkap.

8. Jika Loading Cerita Lama

Jika muncul pesan Antrean belum diambil server, cerita tidak hilang. Data sudah tersimpan, tetapi worker belum berhasil mengambil job dari antrean.

1
Klik Cek worker sekarang
Tombol ini memanggil ulang worker dan menampilkan status terakhir: sukses, gagal, HTTP 401, atau error dari server.
2
Jika HTTP 401
Cek STORY_WORKER_SECRET di Vercel Production. Biasanya secret belum diisi, beda nilai, atau belum redeploy.
3
Jika worker terpanggil tapi antrean tetap
Buka Vercel Logs, cari request /api/jobs/process, lalu lihat apakah error berasal dari Gemini, Supabase, atau provider gambar/audio.
Untuk produksi, gunakan STORY_WORKER_AUTOKICK=true. Cron dengan CRON_SECRET boleh ditambahkan sebagai cadangan agar antrean tetap diproses berkala.

9. Admin White-Label

Dashboard admin ada di /admin. Gunakan halaman ini untuk mengubah tampilan dan pengaturan bisnis tanpa edit code.

Yang bisa diubah

  • Nama brand, logo, tagline, warna.
  • Provider AI, model gambar, voice TTS.
  • Limit cerita per user dan limit profil anak.
  • Harga paket dan copy penjualan.
  • Katalog tema dan template masalah anak.

Syarat admin

  • SUPABASE_SERVICE_ROLE_KEY sudah benar.
  • STORY_WORKER_SECRET sudah diisi.
  • ADMIN_DASHBOARD_SECRET diisi jika ingin password terpisah.
  • SQL 0001_init.sql sudah dijalankan.

10. Cerita Anak Digital English

Menu Cerita Anak Digital (English) berisi katalog video cerita bahasa Inggris. Setiap halaman video memuat video Google Drive, PDF, ringkasan bahasa Indonesia, vocabulary 30 kata dengan phonetic symbol dan TTS, serta 20 soal pilihan ganda.

Manfaat bisnis: Fitur ini bisa dijual sebagai bonus belajar English, materi guru, atau paket reseller dengan konten siap pakai.
